# 🛡️ BTCOE704C: Blockchain Technology — Interactive Quiz & Exam Portal

An interactive, responsive web examination portal and revision guide for **BTCOE704C: Blockchain Technology** (Department of Computer Engineering, SSVPS's Bapusaheb Shivajirao Deore College of Engineering, Dhule).

Includes all **30 Multiple-Choice Questions (MCQs)** across CO-01, CO-02, and CO-03 with real-time scoring, bilingual explanations (English + Hinglish), and deep-dive descriptive breakdowns with custom SVG architectural diagrams.

## 🚀 Key Features

- **30 Comprehensive MCQs:** Fully mapped to CO-01 (Fundamentals), CO-02 (Bitcoin & PoW), and CO-03 (Permissioned Blockchains, RAFT & PBFT).
- **Dual-Language Explanations:** Every question features a formal English breakdown plus an intuitive *Asaan Bhasha Mein* Hinglish explanation.
- **Visual Architecture Diagrams:** High-resolution SVG diagrams for hash pointer linking (avalanche effect) and PBFT 3-phase consensus.
- **Instant Self-Evaluation:** Instant answer verification, live score progress bar, and filters.
- **Zero-Dependency Static App:** High performance, pure HTML5, CSS3, and vanilla JavaScript ready for instant deployment.
